# MoviePilot-Plugins

这是一个MoviePilot的**第三方插件库**，提供影巢签到功能。

## 插件列表

### 影巢签到 (hdhivesign)
- 支持选择每日签到还是赌狗签到
- 支持影巢每日自动签到
- 支持手动触发签到
- 签到状态显示和历史记录
- 签到结果通知
- 定时签到功能
- 签到失败自动重试
- 支持自动登录刷新Cookie

## 安装说明

**本仓库为第三方插件库，需在MoviePilot中添加仓库地址使用**

1. 在MoviePilot的插件商店页面，点击"添加第三方仓库"
2. 添加本仓库地址
3. 添加成功后，在插件列表中找到"影巢签到-改"插件
4. 安装并启用插件
5. 根据下方说明配置插件参数

## 使用说明

### 影巢签到插件
1. 在插件设置中填入账号密码或Cookie
2. 设置签到时间（推荐早上8点，cron表达式：`0 8 * * *`）
3. 启用插件并保存
4. 在插件页面可查看签到历史记录

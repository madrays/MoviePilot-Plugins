# MoviePilot-Plugins

> 本项目采用 AGPL-3.0-only 开源许可证。欢迎在遵守许可证的前提下使用、修改与分享；请保留原始作者与项目出处。详见 [LICENSE](LICENSE) 和 [NOTICE](NOTICE)。

这是一个 MoviePilot **第三方插件库**，同时维护 V2 与 V3 插件扩展。

## 插件列表

### 115Lite（MoviePilot V3）

![115Lite](icons/p115lite.png)

115Lite 是自用精简版，感谢原作者 **DDSRem** 与 **zkmydgth**：

- **DDSRem**：[`DDSRem-Dev/MoviePilot-Plugins`](https://github.com/DDSRem-Dev/MoviePilot-Plugins) 中 `P115StrmHelper`、`P115Disk` 的原始实现
- **zkmydgth**：[`zkmydgth/MoviePilot-Plugins`](https://github.com/zkmydgth/MoviePilot-Plugins) 中 `P115StrmHelper` 的 MoviePilot V3 适配

插件不是重新实现：后端与 Vue 联邦前端均在上述现有实现上定点删减，并把 `P115Disk` 存储能力合并进同一个插件。

#### 主要功能

- 注册独立的 `115Lite` 存储，不与 `P115Disk`、`P115StrmHelper` 的插件 ID 和存储名冲突
- 监控 MoviePilot 整理结果并生成 STRM
- 定时全量同步、增量同步及失效 STRM 清理
- 监控 115 生活事件，处理新增、移动、重命名与删除事件
- 监控待整理网盘目录并自动交给 MoviePilot 整理
- 保留 115→115 批量整理接管；批处理完成后再提交 MoviePilot V3 durable 终态，避免持久任务循环回放
- 支持 115 分享转存、分享生成 STRM、离线下载和指定目录生成 STRM
- 保留同步删除、回收站/最近接收清理、实用工具、本地 STRM 备份、Dashboard 与 MCP 能力
- 存储模块支持目录浏览、创建目录、移动/重命名、删除、下载、快照及空间统计；不提供上传

#### 已移除内容

阿里云盘、签到、侧边栏入口、多端播放、频道搜索、捐赠、上传、FUSE，以及精简版不使用的 CloudDrive2 网盘整理入口和同步删除多版本选项。未点名的原版能力不做额外删改。

#### 兼容性

- MoviePilot：仅支持 V3，宿主版本要求 `>= 3.0.0`
- Python：`>= 3.12`
- Rust 加速轮子：随源码提供 CPython 3.12/3.14 多平台构建；Python 3.13 没有对应上游轮子，会使用纯 Python 降级路径
- 本地精简测试包：Debian/glibc、`x86_64`、CPython 3.14
- Vue 联邦前端：ZIP 根目录包含 `__init__.py` 与 `dist/`，可由“本地插件安装”直接识别

#### 安装与迁移

1. 在 MoviePilot V3 添加插件仓库：`https://github.com/madrays/MoviePilot-Plugins`
2. 安装并启用 `115Lite`
3. 配置 115 Cookie，并在 MoviePilot 目录设置中把资源存储、媒体库存储选择为 `115Lite`
4. 从原版迁移时点击配置页底部的“获取原版配置”；插件会读取 `P115StrmHelper` 配置并换算存储名和路径格式
5. 导入只填充表单，不会自动保存；检查路径后点击“保存配置”
6. 验证 115Lite 正常工作后，建议停用旧的 115 插件监控与整理接管，避免同一生活事件或整理任务被处理两次

插件不预填任何个人目录。路径格式示例：

```text
本地 STRM 目录#/115网盘媒体目录
```

全量同步保存时会规范为：

```text
本地 STRM 目录#/115网盘媒体目录#1
```

最后一段 `1` 表示启用该路径，`0` 表示暂时停用。

#### 简化命令

| 命令 | 作用 |
| --- | --- |
| `/115full` | 立即执行全量同步 |
| `/115inc` | 立即执行增量同步 |
| `/115save` | 把 115 分享转存到待整理目录 |
| `/115share` | 从 115 分享链接生成 STRM |
| `/115down` | 添加离线下载任务 |
| `/115strm` | 为指定网盘目录生成 STRM |

用户可见命令不含下划线；内部事件 action 仍保留旧名称，仅用于兼容原实现。

#### 整理接管说明

- 接管模式会合并目录创建、移动与重命名请求，大批量整理时吞吐高于逐文件执行
- 默认等待约 10 秒聚合一个批次，因此单文件任务可能比原生整理多等待几秒
- 每个任务在产生文件副作用前先写入 V3 durable 计划检查点，并等待批处理真实结果后提交一次终态
- “目标文件已存在且覆盖模式为 `never`”会被结算为单次失败，不会每 15 秒循环回放

#### 依赖与更新提醒

插件显式固定以下兼容组合：

```text
p115client==0.0.9.6.5.1
python-concurrenttools==0.1.8
```

`p115client 0.0.9.6.5.1` 对 `python-concurrenttools` 只有宽松下限，但 `0.1.9` 移除了旧的 `threadpool_map` 名称。不要单独升级其中一个依赖；重新安装或更新插件后如出现 `cannot import name 'threadpool_map'`，先检查宿主实际安装版本。115Lite 同时保留运行时兼容别名，但版本锁仍是首要保障。

其他提醒：

- Cookie 属于敏感凭据，请勿写入仓库、日志或公开截图
- 同时启用旧版与 115Lite 的生活事件监控，可能造成重复生成 STRM 或重复整理
- 分享转存成功不代表后续媒体识别一定成功；整理失败时应查看 MoviePilot 识别结果、覆盖策略和目录映射
- 覆盖模式为“不覆盖”且媒体库已有同名文件时，源文件不会覆盖目标文件，这是预期行为

### 两步验证助手 (twofahelper)
- 生成TOTP两步验证码，无需手动输入
- 配套浏览器扩展实现自动弹出验证码
- 支持多站点验证码管理
- 支持站点图标显示
- 验证码30秒自动刷新
- 支持一键复制验证码

### 后宫管理系统 (nexusinvitee)
- 支持多站点后宫（邀请系统）集中管理
- 自动获取邀请名额和已邀请用户状态
- 监控用户分享率健康状况
- 检测禁用账号和低分享率用户
- 定时自动刷新数据，支持手动刷新
- 美观的数据展示界面
- 适配多种NexusPHP站点结构

### 蜂巢论坛签到插件（fengchaosignin）
- 使用“隐秘的角落”生成的 MP 专用 API Key 接入，无论坛账号、密码、Cookie 或页面抓取
- 自动完成蜂巢签到，并在插件内展示论坛头像、勋章、连签摘要与最近签到记录
- 从 MoviePilot 本地统计模型同步 PT 人生；失败使用单一非阻塞延迟任务并复用同一幂等批次，不访问任何 PT 站点
- 定时任务自动随机错峰，插件详情页只读本地缓存，不因打开页面请求论坛

## 安装说明

**本仓库为第三方插件库，需在MoviePilot中添加仓库地址使用。**

- MoviePilot V2：读取 `package.json` 与 `plugins/`，保持现有插件版本和行为。
- MoviePilot V3：读取 `package.v3.json` 与 `plugins.v3/`，各插件保持独立且单调递增的语义版本。

1. 在MoviePilot的插件商店页面，点击"添加第三方仓库"
2. 添加本仓库地址：`https://github.com/madrays/MoviePilot-Plugins`
3. 添加成功后，在插件列表中找到需要的插件
4. 安装并启用插件
5. 根据下方说明配置插件参数

> V3 会优先选择独立的 `plugins.v3` 实现，不再依赖旧插件目录的兼容回退加载。

发布 V3 更新前运行：`python3 scripts/validate_v3_plugins.py`。该检查会阻止市场 ID、目录、源码名称、版本或配置前缀不一致，以及误声明不存在的 Release 安装包。

## 使用说明

### 两步验证助手
1. 安装MP插件后，下载并安装浏览器扩展
2. 浏览器扩展用于添加和管理TOTP站点配置
3. MP插件负责生成验证码，浏览器扩展负责显示和填写
4. 无需手动输入API或其他复杂配置
5. 详细说明请查看[TOTP浏览器扩展说明](#totp浏览器扩展说明)

### 后宫管理系统
1. 确保已在MoviePilot中添加并配置好需要管理的NexusPHP站点
2. 在插件设置中选择要管理的站点（可多选）
3. 设置数据刷新频率（推荐早上8点，cron表达式：`0 8 * * *`）
4. 可选择是否在启动时立即刷新数据
5. 启用插件并保存
6. 在插件页面查看后宫数据统计和详情

### 蜂巢论坛签到插件
1. 获取Cookie：登录蜂巢论坛后，按F12打开开发者工具，在网络或应用程序选项卡中复制Cookie
2. 在插件设置中填入Cookie
3. 设置签到时间（推荐早上8点，cron表达式：`0 8 * * *`）
4. 启用插件并保存

## TOTP浏览器扩展说明

TOTP两步验证助手需要配合浏览器扩展使用：

1. 下载浏览器扩展：[下载链接](https://github.com/madrays/MoviePilot-Plugins/raw/main/TOTP-Extension.zip)
2. 解压下载的文件
3. 在浏览器的扩展管理页面中选择"加载已解压的扩展程序"
4. 选择解压后的文件夹
5. 扩展安装完成后，点击浏览器扩展图标进入设置
6. 添加站点和密钥信息
7. 浏览扩展会自动从MoviePilot获取验证码并在需要时弹出

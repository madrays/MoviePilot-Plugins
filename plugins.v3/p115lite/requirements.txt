# ⚠️ p115client 必须与 python-concurrenttools 成对锁定，不要单独升任一方。
#
# 【为什么锁 concurrenttools == 0.1.8】
# p115client 0.0.9.6.5.1 声明 `python-concurrenttools>=0.1.8` 但没有上限，
# 而 upstream concurrenttools 0.1.9 把 threadpool_map 改名为 thread_conmap，
# 导致 p115client/tool/upload.py 第 23 行的
#     from concurrenttools import threadpool_map
# 抛 ImportError —— 本插件 21 个测试模块集体 import 失败、CI 变红。
# 因此必须显式压住上限，让解析结果停在 0.1.8。
# （注：CI 的 --find-links 只是"额外候选来源"，pip 仍会与 index 结果合并后
#   按版本取高，所以 wheels/ 里放 0.1.8 并不能自动拦住 0.1.9。）
#
# 【为什么锁定 0.0.9.6.5.1 而不升到 0.0.9.7.2】
# 0.0.9.7.x 对 iterdir 模块做了一次大重构（__all__ 砍掉 29 个符号），
# 改名后又移除了本插件正在使用的下列 API，升级会直接打断插件：
#     iter_file_list            -> iterdir
#     iter_files_with_path_skim -> iter_files_skim(with_path=True)
#     traverse_tree_with_path   -> traverse_tree(with_path=True)
# 其中 full_sync_iter_function 是用户可见配置项，两个取值在新版里均已失效。
# 要升级 p115client，需先完成上述 14 处调用点的适配改造。
